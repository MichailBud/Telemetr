# Курсовой проект по телеметрии по теме: «Разработка подсистемы передачи телеметрического сигнала»

Целью данного курсового проекта является разработка и практическая реализация аппаратно-программной подсистемы передачи телеметрического сигнала. 
Подсистема предназначена для приема агрегированных данных по интерфейсу SPI и их ретрансляции по беспроводному радиоканалу LoRa
